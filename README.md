## 💻 Portfolio

### 📦 Shipment Management System (GAS)
Googleスプレッドシートでの出荷管理を自動化するシステム。

主な機能
- チェックボックス操作で出荷データを自動転記
- 出荷日ごとのシート自動生成
- シートの自動並び替え
- 重複データ防止
- 過去日付シートの自動ロック

実際の業務フローを想定して設計した業務改善ツールです。

🔗 Repository  
https://github.com/kyuuri22/shipment-management-gas
